# Machine Consciousness ↔ Model Hub boundary

Canonical map: [Machine Consciousness cross-repository integration v1](https://github.com/4citeB4U/Machine-Consciousness/blob/main/docs/architecture/leeway-cross-repository-integration-v1.md).

Model Hub is a bounded capability provider. Machine Consciousness selects a model or team through governed policy; Model Hub manages admitted catalog identity, adapter lifecycle, bounded wake/pause/swap behavior, and model-specific execution. Ollama, Hugging Face, llama.cpp, vLLM, and provider APIs are adapters, not LeeWay authority.

Model metadata or a stored weight hash is not physical inference proof. Model output remains a proposal until Edge GPU/Device Bridge execution, Veritas, Receipt Authority, and Continuum readback complete. `PAUSED_RESIDENT_NOT_PHYSICALLY_PROVEN` is an honest state; zero VRAM, token savings, and quality retention require measurements.
