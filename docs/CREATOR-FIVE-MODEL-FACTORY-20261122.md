### Engineering corrections to the proposed in-place updating concept

LoRA, QLoRA and distillation are **valid candidate training approaches**, but do **not** promise equal bytes, no temporary disk growth or conserved accuracy. A LoRA delta applied to a supported projection is `W_new = W_base + (alpha / r) · (B @ A)`. The **parameter shape and count generally remain the same** after merging that supported adapter, but byte count also depends on precision, quantization scheme, metadata, tokenizer changes and packaging. A QLoRA adapter is generally trained while the quantized base is frozen and needs a careful dequantized-merge then compatible re-quantization path for a standalone deployable GGUF; direct repeated merges into quantized tensors can accumulate rounding error. See [Hugging Face PEFT LoRA docs](https://huggingface.co/docs/peft/package_reference/lora) and [quantization guide](https://huggingface.co/docs/peft/developer_guides/quantization).

Therefore do **not** update in place. Keep the original bytes immutable and hash-pinned, train in a separate bounded workspace, merge only to a staged copy when architecture/adapter supports it, re-quantize by tested model backend, and record candidate size, peak temporary disk, peak RAM/CPU, output behavior and performance. Only allow a deployable replacement whose exact measured packaged bytes are **no greater than its own measured prior version** AND whose held-out acceptance tests, rights, Formula, original Runtime, independent Veritas PRE/POST, Receipt Authority and Continuum readback pass. A smaller file alone never authorizes swap. A Modelfile/System prompt changes prompting and possible metadata, not the mathematical weights; optional calibrated inference limits do not imply training.

**Every-three-hour review remains a test/evaluation/skill-teaching loop.** Automatic per-three-hour LoRA retraining would impose temporary storage, training-memory and quality risks and must not be activated as ordinary learning without a separate owner-approved, reproducible and independently verified weight training job.
